# Library artwork

Created with the built-in OpenAI image generation tool for the interactive Bookshelf Library mode, 17 September 2026. The WebP files are optimized versions of the generated artwork.

- `library-room.webp`: warm library environment behind the interactive books.
- `walnut-grain.webp`: repeating material for the shelf surface and front edge. Its position follows the book carousel, with slower movement in the room background.

## Generation prompts

### Library environment

Use case: photorealistic-natural. Asset type: background image for an interactive 3D bookshelf website. Create a wide cinematic photograph of a quiet, elegant private library made from warm medium-dark walnut. View from close to a bookshelf, looking along a long row of shelving which recedes gently toward the right. The background contains shelves of softly out-of-focus books and warm ambient library lighting; no readable text, people, lamps in the foreground, signage, logos, or watermark. The foreground must remain empty because real interactive book covers and a wooden shelf will be composited over this image. The lower half and centre should be softly shadowed and visually calm, without a dominant object. Photoreal natural wood, rich brown and soft amber tones, subtle depth of field, restrained contrast, refined and cosy rather than fantasy or overly ornate. Wide landscape composition, preferably 1536 by 1024.

### Walnut shelf material

Use case: product-mockup. Asset type: seamless wood material texture for a moving 3D bookshelf surface on a website. Create a photorealistic close-up, perfectly straight-on orthographic texture of a single continuous finely finished walnut board. The wood grain runs horizontally left to right, with subtle natural flowing fibres and a few quiet variations, warm medium walnut brown, smooth satin finish. This is ONLY a flat material texture, edge to edge: no shelf edges, perspective, bevels, books, room, objects, text, watermark, vignette, cast shadows, border, or obvious plank seams. Even diffuse illumination. It must tile seamlessly horizontally and vertically, with especially continuous left and right edges, so moving the texture feels like travelling along one very long wooden shelf. Landscape 1536 by 1024.
